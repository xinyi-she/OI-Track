# 刷题独立做出率追踪

一个简单的网页，记录每天刷题情况，看自己“完全靠自己 AC”的比例有没有进步。

## 功能

- 记录日期、难度、是否独立做出
- 统计最近 $7/30/90$ 天的独立做出率
- 画趋势图（每日+ $7$ 日均线+ $14$ 日均线）
- 按洛谷/CF/AT难度段分组统计
- 导出/导入 JSON 备份
- 单条删除+批量重置测试数据

## 使用

直接用浏览器打开 [此处](https://xinyi-she.github.io/OI-Track/) 就能用。
数据按浏览器隔离，换浏览器或清缓存会丢，记得定期导出。

本网页由我让 AI 完成，如有错误请联系。
